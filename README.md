# A&C Trade Hub

Welcome to **A & C Trading ** — a clean and modern frontend UI for A & C Trading, a distributor company focused on delivering quality goods and services with efficiency and trust in Nepal.

## 🌐 About

This project showcases the web presence of **A & C Trading**, designed with a user-friendly interface and responsive layout. The goal is to highlight key offerings, build brand credibility, and provide essential contact info for potential clients and partners.

## 💼 Features

- 🧭 Home, About, and Contact pages
- 📦 Product/Service showcase sections
- 📱 Fully responsive layout (Mobile + Desktop)
- ✨ Built with clean code and design-first approach

## 🛠️ Tech Stack

- Next.js, Framer
- Tailwind CSS
- Designed for easy backend integration 

Deployed at: wwww.aandctrading.com
